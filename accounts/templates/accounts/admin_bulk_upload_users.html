File format

Your Excel file needs these column headers in row 1 (order doesn't matter):

username, email, password, first_name, last_name, phone_number, company_role, section, company_branch

username, email, and password are required for every row. Rows with a username that already exists are skipped, not overwritten.

Valid company_role values: admin, manager, supervisor, operator, qc_technician, sales_representative, engineer, other — valid section values: extrusion, printing, lamination, slitting, bag_making, quality_control, maintenance, sales, other — valid company_branch values: kawempe. The downloaded template includes a "Valid Values" reference sheet too.
